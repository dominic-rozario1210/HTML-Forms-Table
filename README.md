# Student Registration Form

A simple HTML project that demonstrates how to create a student registration form and display submitted student details in a table.

## Features

- Student registration form
- Full Name input
- Email input
- Password input
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth input
- Submit button
- Submitted students table

## Technologies Used

- HTML5

## HTML Concepts Practiced

- HTML document structure
- Forms
- Labels
- Text, email, and password inputs
- Radio buttons
- Checkboxes
- Date input
- Buttons
- Tables
- Table headings and data cells
- Cell padding and borders
